# FinTech Loan Credit Risk Dashboard - Power BI

## Project Overview

This project is an interactive FinTech Loan Credit Risk Dashboard developed using Microsoft Power BI.

The dashboard provides insights into loan disbursement, repayment performance, delinquency, credit risk, NPA, interest income, and loan portfolio performance.

The report consists of three interactive pages designed to analyze different aspects of the loan portfolio.



## Objectives

The main objectives of this project are:

- Analyze overall loan portfolio performance
- Monitor total loan disbursement and active loans
- Analyze loan repayment and collection performance
- Track overdue amounts and delinquency
- Analyze credit risk and NPA
- Compare different loan types
- Analyze loan performance across cities
- Monitor monthly and yearly trends
- Provide interactive filtering for data analysis



## Report Pages

### 1. Overview

The Overview page provides a high-level summary of the loan portfolio.

It includes:

- Total Disbursed Amount
- Active Loans
- Collection %
- NPA %
- Monthly Loan Disbursement Trend
- Risk Distribution
- Portfolio by Loan Type
- Loan Type and Date filters

This page provides an overall view of the loan portfolio and its risk distribution.

## Key Metrics

| Metric | Description |
|---|---|
| Total Disbursed Amount | Total amount of loans disbursed |
| Active Loans | Number of currently active loans |
| Collection % | Percentage of EMI amount collected |
| NPA % | Percentage of loans classified as non-performing |
| Total EMI Due | Total EMI amount due |
| Total EMI Collected | Total EMI amount collected |
| Overdue Amount | Total outstanding overdue amount |
| Total Interest Income | Total interest income generated |
| Total NPA Amount | Total amount associated with non-performing loans |



## Interactive Features

The dashboard includes:

- Interactive filters
- Loan type filtering
- Date filtering
- City filtering
- Customer segment filtering
- Cross-visual interactions
- Monthly and yearly trend analysis
- Risk distribution analysis
- Comparative analysis across loan types and locations
